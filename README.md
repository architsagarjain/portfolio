# ARCHT — Personal Site (React + Framer Motion)

## Run locally
```
npm install
npm run dev
```

## Deploy free on Vercel (recommended)
1. Push this folder to a GitHub repo
2. Go to vercel.com → Add New Project → Import the repo
3. Vercel auto-detects Vite. Click Deploy. Done.

Every git push auto-deploys. Free tier: 100GB bandwidth, HTTPS, custom domain support.

## Quickest option (no git)
The `dist/` folder is the pre-built site — drag it onto app.netlify.com/drop and it's live.
(If you edit the code, run `npm run build` to regenerate dist.)

## Custom domain later
Buy a domain (~₹700/yr), then in Vercel/Netlify → Domain settings → add it. HTTPS is automatic.
